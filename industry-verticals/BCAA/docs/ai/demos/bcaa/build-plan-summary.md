## Sections needing attention

The eight quick actions need one small list component. Existing fixed-column components do not fit the eight-item row. Links opening production BCAA modal flows need direct public destinations verified during content mapping.

## Variant decisions

Recommended: BCAA-specific variants for transparent navigation, left-aligned carousel copy, blue card panels, savings/blog grids and compact membership banner. Generic variants reuse Prospera layouts with the approved colors and fonts, so the layout match is less exact.

## Components by type

- Nine body sections in headless-main; existing Header and Footer in partial designs.
- Existing datasource schemas reused where they fit. One new list datasource for eight quick actions.
- Shared source example items retained; BCAA-specific datasources created. No changes to CPUC or Prospera apps.
- Marketer MCP is unavailable; UI-based assembly is the available fallback. Confirm every save in small batches.

## Build order

Extract exact copy/images and verify action destinations; create BCAA-specific datasources; apply theme; build quick actions and approved variants; assemble existing Home and partial designs; verify desktop/mobile, images and links.
